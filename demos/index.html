Cartolina JS — demos

Simple terrain
Global terrain with hillshading and no texture overlay. Minimal style; good starting point.
Complex terrain
Illumination, bump maps, specular maps, and point labels. Renders the Grossglockner area.
Map — generic style loader
style= accepts a full URL to any style JSON file, or a short name for one of the predefined styles: simple, satellite, complex, full.

pos= sets the initial camera position.

For the predefined styles, backend= selects the tile server: prod (cdn.tspl.re/mapproxy), test (localhost/mapproxy), or dev (localhost:3071).
Non-interactive
Map with no built-in navigation (interactive: false). Pan, orbit, zoom, hit-testing, and a geodata free layer are all wired by hand. Reference for embedders who provide their own UI.
Relief Lab
Interactive controls for illumination, shading weights, atmosphere, vertical exaggeration, and render flags. Live readback from renderer state.
Depth test
Elevation and depth overlay diagnostic.
Custom overlay
Custom WebGL overlay drawn into the map's render pass. Demonstrates the surface drawing API for embedders adding their own geometry.
Waypoint
Geographic story map. Keyboard navigation flies between JSON-configured positions; image markers stay anchored to geographic coordinates. Embeddable as a plain ES module (e.g. in reveal.js).
